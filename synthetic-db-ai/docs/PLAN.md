88 tables, 41 physical FKs (all intra-service) and **111 logical cross-service references** (user_id, product_id, order_id,
shipment_id, seller_id, offer_id, variant_id, warehouse_id, address_id …).

Why a catalog introspection and not a SQL parser: the migrations `ALTER`/`DROP CONSTRAINT`, add generated columns
(`variant_key`, `search_vector`), partial/functional unique indexes and `DO`/function bodies. Reading `pg_catalog` of a
migrated database gives the exact end state; the repository scan adds services, migration lists, JPA entities and Flyway
default schemas.

## 2. Business logic that shaped the generators
* `PricingService`: subtotal − discount − coins + shipping; free shipping ≥ 499 INR / 25 other, fee 40 / 4.99, members free; INR GST 18 % inclusive, CGST+SGST for Karnataka else IGST; delivery days 2/3/5 by pincode prefix (7 international).
* Order/shipment lifecycle (`PLACED → CONFIRMED → PACKED → SHIPPED → OUT_FOR_DELIVERY → DELIVERED`, `CANCELLED` before shipping), order status = least advanced shipment; returns `REQUESTED/APPROVED/PICKED_UP/REFUNDED/REJECTED`; COD collected on delivery.
* `CoinService` (1 coin / 100 INR or / 1 other unit, members ×2, 365-day expiry, referral reward 100) and `LedgerService` (SALE, −COMMISSION %, −FEE 10 INR / 0.25 when commission > 0, reversals keyed by return).
* Wallet balance ≥ 0, gift-card lifecycle, coupon limits (per user, total, first order, window, currency), one review per (product, user), stock `reserved ≤ quantity`.

## 3. Design (decisions in `DecisionLog.md`)
1. Discovery = repo scan + read-only catalog introspection → `schema_inventory.json`.
2. Deterministic, index-addressable world ⇒ memory-flat, parallel, resumable, cross-DB consistent.
3. Stages: static → customer chunks → catalog chunks → finalize; per-(chunk, DB) transactions; SQLite state.
4. Emitter enforces the schema contract on every COPY; generators never touch SQL.
5. Planner measures size from the generators + catalog instead of using a constant bytes-per-row.
6. Validator re-derives the invariants in SQL, independent of the generator code.
