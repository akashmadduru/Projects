# Step 2: Requirements (CPO)
Delegate to `forge-cpo` with: work id, folder path, "read objective.md; write requirements.md".
Gate (you check it): requirements.md exists; ACs are numbered AC-1..n; each AC names an observable
result (status, field, state, message); non-goals are listed. If an AC is vague, send it back once
with the specific problem. Open questions from the CPO go to the Owner.
